# hammers

Sign-up page for the NY Hammers 12U Thanksgiving Day Boxes fundraiser, served at
https://hammers.mikeboxer.com via GitHub Pages (branch `main`, root).

The page talks to an Apps Script web app (URL in `CONFIG.apiUrl` in `index.html`). Its
source lives in `boxoprofundo/boxoprofundo.github.io` under `hammers/apps-script/`.
Payment handles and contact details are in the `CONFIG` block near the bottom of `index.html`.
